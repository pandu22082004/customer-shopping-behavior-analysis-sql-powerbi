**Customer Shopping Behavior Analysis Using SQL Server & Power BI**

**Project Objective**

This project analyzes customer shopping behavior to identify purchasing patterns, top-performing products, customer segments, and revenue trends. SQL Server was used for data cleaning and analysis, while Power BI was used to create an interactive dashboard and generate business insights for data-driven decision-making.

## Key Findings

- Clothing generated the highest revenue (₹102,968).
- Customers aged 56+ contributed the highest revenue.
- Fall generated the highest seasonal revenue.
- Montana was the highest revenue-generating location.
- Blouse, Shirt, and Dress were the top revenue-generating products.
- Non-subscribers generated higher revenue than subscribers.
